# Process JSON

::: warning Removed in 7.0
The Process JSON no longer exists: the Gradle task `generateBpmnModelJson`, the Maven goal `generate-bpmn-json`, the web endpoint `POST /api/generate-json` and the tab in the web app are gone. The [v7 Migration Guide](/changelog/v7) names the alternatives.
:::

Files written by 6.x keep validating: the schema stays published at [`process-model/2.0.json`](https://miragon.github.io/bpmn-to-code/schema/process-model/2.0.json). The format itself is described in the [v6 Migration Guide](/changelog/v6#why-the-format-changed).
