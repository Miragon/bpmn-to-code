# @miragon/bpmn-to-code-runtime

The types the TypeScript Process APIs generated by [bpmn-to-code](https://miragon.github.io/bpmn-to-code/) are built from (`FlowNode`, `SequenceFlows`, `BpmnErrorDefinition`, …) and `ProcessPath`, a compile-checked walk over the generated `FlowNodes`.

```sh
npm install @miragon/bpmn-to-code-runtime
npm install --save-dev @miragon/bpmn-to-code
```

Use the same version for both: the generator writes code against the runtime of its own version.

```ts
import { ProcessPath } from "@miragon/bpmn-to-code-runtime";
import { BikeLeasingProcessApi } from "./process/BikeLeasingProcessApi.js";

const path = ProcessPath.from(BikeLeasingProcessApi.FlowNodes.StartEventLeasingRequestReceived)
  .then((next) => next.serviceTaskValidateApplication)
  .then((next) => next.businessRuleTaskCheckCreditRating);

// path.ids: the element ids in walk order, for the assertions of your engine's test library
```

See [Process paths](https://miragon.github.io/bpmn-to-code/guide/process-path) for every step.
