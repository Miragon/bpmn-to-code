# @miragon/bpmn-to-code-runtime

The types the TypeScript Process APIs generated by [bpmn-to-code](https://miragon.github.io/bpmn-to-code/) are built from (`FlowNode`, `SequenceFlows`, `BpmnErrorDefinition`, …) and `ProcessPath`, a compile-checked walk over the generated `FlowNodes`.

```bash
npm install --save-exact @miragon/bpmn-to-code-runtime
npm install --save-dev --save-exact @miragon/bpmn-to-code
```

Use the same version for both: the generator writes code against the runtime of its own version, and `@miragon/bpmn-to-code` declares this package as a peer dependency of exactly that version.

```ts
import { ProcessPath } from "@miragon/bpmn-to-code-runtime";
import { BikeLeasingProcessApi } from "./process/BikeLeasingProcessApi.js";

const ids = ProcessPath.from(BikeLeasingProcessApi.FlowNodes.StartEventLeasingRequestReceived)
  .then((next) => next.serviceTaskValidateApplication)
  .then((next) => next.businessRuleTaskCheckCreditRating).ids;
```

Documentation: https://miragon.github.io/bpmn-to-code/guide/process-path#from-typescript
