# Miragon.BpmnToCode.Runtime

> **Experimental, not yet published.** This package may change in a minor release and is not on nuget.org yet.

The types the C# Process APIs generated by [bpmn-to-code](https://miragon.github.io/bpmn-to-code/) are built from (`IFlowNode`, `SequenceFlows`, `BpmnErrorDefinition`, …) and `ProcessPath`, a compile-checked walk over the generated `FlowNodes`.

```xml
<ItemGroup>
  <PackageReference Include="Miragon.BpmnToCode.Runtime" Version="x.y.z" />
</ItemGroup>
```

Use the version of the tool that generated the code. `Miragon.BpmnToCode.MSBuild` adds this package for you.

```csharp
using Miragon.BpmnToCode.Runtime;
using Api = MiraVelo.Process.BikeLeasingProcessApi;

string[] ids = ProcessPath.From(Api.FlowNodes.StartEventLeasingRequestReceived)
    .Then(n => n.ServiceTaskValidateApplication)
    .Then(n => n.BusinessRuleTaskCheckCreditRating)
    .Ids;
```

Documentation: https://miragon.github.io/bpmn-to-code/guide/process-path#from-c-sharp
