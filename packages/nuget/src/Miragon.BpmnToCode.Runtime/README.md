# Miragon.BpmnToCode.Runtime

The types the C# Process APIs generated by [bpmn-to-code](https://miragon.github.io/bpmn-to-code/) are built from (`IFlowNode`, `SequenceFlows<T>`, `ElementId`, `MessageName`, …) and `ProcessPath`, a compile-checked walk over the generated `FlowNodes`.

Use the same version as the generator. `Miragon.BpmnToCode.MSBuild` adds this package for you.

```csharp
using Miragon.BpmnToCode.Runtime.Path;
using static MiraVelo.Process.BikeLeasingProcessApi;

var path = ProcessPath.From(FlowNodes.StartEventLeasingRequestReceived.Instance)
    .Then(next => next.ServiceTaskValidateApplication)
    .Then(next => next.BusinessRuleTaskCheckCreditRating);

// path.Ids: the element ids in walk order, for the assertions of your engine's test library
```

See [Process paths](https://miragon.github.io/bpmn-to-code/guide/process-path) for every step.
